# 朝活コーチ（Asakatsu Coach）

毎朝の朝活メニューを**判断ゼロ**で決めるための個人用PWA。
起床直後の3つの質問（目覚め・仕事負荷・天気）に答えると、曜日テンプレートと当日のコンディションからその日のワークアウトメニューを自動決定する。

> 設計思想：意志力を信用しない。「何をやるか」を毎朝考えさせない。

## 使い方

1. スマホのChromeで公開URLを開く
2. メニュー →「ホーム画面に追加」でアプリとしてインストール（オフライン動作可）
3. 時計アプリで毎朝5:00のアラームを設定し、鳴ったらアイコンをタップ
4. 3問に答える（約30秒）→ 今日のメニューが表示される →「このメニューでやる」で記録

## 画面フロー

```
スタート（前回の実施記録を表示）
  → Q1 目覚め（スッキリ / ふつう / イマイチ）
  → Q2 今日の仕事・予定の負荷（軽め / ふつう / 重い）
  → Q3 天気（晴れ・くもり / 雨）
  → 結果（場所・メニュー・応援メッセージ・曜日別Tips）
  → 完了（localStorageに記録）
```

## メニュー決定ロジック

### 1. 曜日ベーステンプレート（v2）

原則：**ジムに行く日＝必ず筋トレ**。低強度有酸素だけの日はジムに行かず外へ。

| 曜 | 場所 | 内容 | 筋トレ |
|---|---|---|---|
| 月 | ジム | トレッドミル歩き10分 → マシン筋トレ3種 各15×3 | ● |
| 火 | 外 | 早歩き or 会話ペースの軽ジョグ 20〜25分（飲酒明け・低強度厳守） | − |
| 水 | 家周辺 | 早歩き15分＋瞑想長め（断食日・強負荷禁止） | − |
| 木 | ジム | ラン5km（週の本命）→ 筋トレ3種 各15×2（軽め） | ●軽 |
| 金 | ジム | 筋トレ3種 各15×3 ＋ 余裕があれば傾斜ウォーク15分 | ● |
| 土 | 外 | イージーラン（飲酒明けは早歩き） | − |
| 日 | 家 | 自重タバタ4分＋スクワット3分＋プッシュアップ3分 or 休養＋モビリティ | ●自重 |

### 2. コンディション補正（レベル制）

基準レベル2からの加減算：

- 目覚めイマイチ → −1
- 仕事負荷が重い → −1
- 目覚めスッキリ かつ 負荷軽め → +1
- 水曜は上限2（断食×会議日のため絶対に上げない）

| レベル | 挙動 |
|---|---|
| 3 | 標準＋軽い追い込み提案（ランは+1kmまで。怪我予防優先） |
| 2 | 標準メニュー |
| 1 | 1段軽減（筋トレ3セット→2セット、ラン→早歩き等） |
| 0以下 | 最小メニュー（自宅タバタ4分＋プレハブのみ） |

### 3. 雨の日ルール

雨なら外にもジムにも行かない。代替は2パターンのみ（認知負荷最小化）。

- 雨 × 筋力日（月木金）→ **自宅A**：プッシュアップ15×3／自重スクワット20×3／グッドモーニング15×3（3秒かけて下ろすテンポでマシン負荷を代替）
- 雨 × 有酸素日（火土）→ **自宅B**：タバタ4分＋スクワット3分＋プッシュアップ3分
- 雨 × 水曜 → 室内モビリティ＋瞑想のみ

### 4. その他のルール

- **毎朝共通**：運動前プレハブ3〜4分（片脚カーフレイズ各15×2／足首ドーシフレクション各10／レッグスイング各10）、締めに水シャワー2分→瞑想10分
- **連続ラン検知**：前日にランを実施済みで当日もラン系なら、早歩きへの置き換えを提案
- **曜日別メッセージ**：水曜=ファスティング応援／火土日朝=飲酒明けの注意／金土月=晩酌可の日の健康Tips

## データ

- 実施記録は `localStorage`（キー: `asakatsu_history`）に直近60日分保存
- **サーバーへの送信は一切なし**。すべて端末内で完結
- ブラウザのサイトデータを削除すると履歴も消える（日次ログの正はNotion側で管理する前提）

## 技術構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて単一ファイル） |
| `manifest.json` | PWAマニフェスト（アプリ名・アイコン・スタンドアロン起動） |
| `sw.js` | Service Worker（全アセットをキャッシュしオフライン動作） |
| `icon-192.png` / `icon-512.png` | ホーム画面アイコン |

フレームワーク・ビルド・外部依存なし。ホスティングはGitHub Pages（HTTPS必須。`file://` ではPWAとして動作しない）。

## 更新手順

1. `index.html` を編集（メニュー変更は `TEMPLATE` / `HOME_A` / `HOME_B` 定数を修正）
2. `sw.js` の `CACHE` バージョン（例: `asakatsu-v2` → `asakatsu-v3`）を上げる
3. GitHubに上書きアップロード → 次回オンライン起動時に自動反映

## 背景

朝活プロトコルv2（2026-07策定）の実装。設計上のコア判断は3つ：

1. **怪我リスク最優先** — 本気ランは週2（木・土）に制限し、低衝撃有酸素とプレハブで補完
2. **筋トレは実質週4** — ジム3回＋日曜自重。木曜は金曜との連日を考慮し軽め
3. **認知負荷ゼロ** — 器具・メニューの選択肢を固定し、朝の意思決定をアプリに委譲
